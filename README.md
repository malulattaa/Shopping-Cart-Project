# Shopping Cart Project

Sistema de carrinho de compras desenvolvido para simular o funcionamento básico de uma loja virtual, aplicando conceitos de estruturas de dados e desenvolvimento web.

## Sobre o Projeto

O projeto escolhido foi o desenvolvimento de um sistema de carrinho de compras, permitindo o gerenciamento de produtos, estoque e compras de forma dinâmica.

O sistema contará com funcionalidades como:

- Cadastro de produtos
- Adição e remoção de itens do carrinho
- Desfazer última ação utilizando pilha
- Histórico de compras utilizando lista encadeada
- Busca e ordenação de produtos
- Localização rápida utilizando tabela hash
- Controle de estoque
